# 2 и 3

Небольшой набор калькуляторов в духе старых языков программирования СССР и современных консольных систем.

## Что реально запускается сразу

### Ubuntu

```bash
cd ~/calculators_ussr
python3 calculator.py
bash calculator.sh
node calculator.js
sudo apt update && sudo apt install gcc
 gcc calculator.c -o calculator && ./calculator
```

В Python и Node.js можно вводить выражения вроде `2+3*4`. В Bash и C вводите строку вида `2 + 3`.

### Android-телефон

Установите **Termux** из F-Droid, затем выполните:

```bash
pkg update
pkg install python nodejs clang
```

Перенесите файлы в Termux и запустите:

```bash
python calculator.py
node calculator.js
clang calculator.c -o calculator && ./calculator
```

Если нужен только самый простой вариант, достаточно Python.

## Кто создавал исторические языки

Здесь указана не всегда этническая национальность, а подтверждаемая историческая принадлежность: страна, республика или научная школа. Для советских учёных слово «национальность» в современных источниках часто не фиксируется однозначно.

- **ПП-1 и ПП-2** — коллектив под руководством Алексея Андреевича Ляпунова, советского математика; работа велась в МГУ.
- **АПЛ** — Екатерина Логиновна Ющенко, украинская советская учёная, и Владимир Королюк; разработка велась в УССР.
- **Альфа** — Андрей Петрович Ершов и его новосибирская школа; Ершов — советский российский математик и программист.
- **ЛЯПАС** — Аркадий Андреевич Закревский, советский и белорусский учёный; работа связана с Минском и Институтом кибернетики.
- **АЛМО** — коллектив советских инженеров; среди известных участников вариантов для М-220 упоминаются Алексей Маклаков, Евгений Ермаков и В. В. Богданов. Единого общепринятого списка авторов исходного языка нет.
- **СИГМА** — инициирована Андреем Ершовым и развивалась коллективом Новосибирской школы программирования.
- **РЕФАЛ** — Валентин Фёдорович Турчин, советский математик и кибернетик; позже работал в США.
- **ЭЛЬ-76** — Владимир Михайлович Пентковский и коллектив ИТМиВТ; советская инженерная школа.
- **РАПИРА** — коллектив выпускников НГУ под руководством Геннадия Александровича Звенигородского; советская новосибирская школа.
- **ДРАКОН** — Владимир Паронджанов и специалисты ракетно-космической отрасли СССР. Для этого проекта корректнее указывать советскую научно-инженерную среду, а не приписывать всем участникам одну национальность.

Для национальности авторов я не использую догадки: гражданство, республика и этническое происхождение — разные сведения.

## Исторические варианты

- `calculator.alg` — учебный каркас ALGOL-60. Точный ввод и вывод зависели от конкретной ЭВМ и транслятора, поэтому этот файл не является универсальным современным исходником.
- `calculator.refal` — короткий пример в стиле РЕФАЛ. Для вычислений нужен интерпретатор РЕФАЛ и его библиотека арифметики.
- **РАПИРА, ЭЛЬ-76, ЛЯПАС, АЛМО и ПП-2** не имеют единого современного компилятора, который можно было бы честно указать командой `apt install`. Их запуск обычно требует музейного эмулятора, архивного транслятора и конкретной модели ЭВМ.

Для повседневного телефона или Ubuntu лучше всего использовать `calculator.py`: он маленький, работает без графики и сохраняет дух старых консольных машин.
